# 掌握闸门状态（掌握复测 / 只评估）

用于掌握复测（7 天后）和只评估模式的证据汇总。会话收束用 `learning-map.md`。只标状态和证据，不算分、不算百分比。

```text
<主题> · <日期>
判定（只评估）：本次过关 / 未过关 / 未判定
判定（掌握复测）：已掌握 / 未掌握

解释  过    第 2 题：能讲清输入、状态和输出
应用  过    第 4 题：新场景独立做对
纠错  部分  第 5 题：指出错误，但修正需要提示
迁移  未测
保持  未测（7 天后）
校准  部分  第 6 题：预测和结果对不上，能说出差在哪
```

## 状态

| 状态 | 含义 |
|---|---|
| `过` | 独立完成，并能说出理由 |
| `部分` | 需要提示，或答案对但理由错，或表现不稳定 |
| `未过` | 错误，或没有可用证据 |
| `未测` | 本次没测；不要当成通过 |

表格里可简写为 `✅ / ◐ / ✗ / ○`，但不要只用符号。

## 本次判定

- `本次过关`：解释、应用、纠错三项都是 `过`。
- `未过关`：解释、应用、纠错任一不是 `过`。
- `未判定（轻量或只评估）`：只测了部分闸门，写明哪些 `未测`。

## 掌握复测（7 天后，只有这里能判“已掌握”）

- `已掌握`：六项全是 `过`，其中保持至少隔 7 天复测，迁移用新场景（至少改一个结构变量）。
- `未掌握`：六项中任一不是 `过`；写明哪一项、什么证据、下一步练什么。
- 掌握复测前不要填“已掌握/未掌握”；复测时填。

## 规则

- 每项后面写一句证据；指不到证据就标 `未测`。
- 不写百分比、不画进度条、不做跨项平均。
- 只评估只填“本次判定”；掌握复测填“已掌握/未掌握”，不填“本次过关”。

## 结论写法

> 本次过关；未验证掌握。迁移和保持未测，校准只有部分证据。7 天后用新场景复测迁移，再做一次不看笔记的回忆。

不要写总分或“掌握度”；掌握不是分数，是证据状态。
