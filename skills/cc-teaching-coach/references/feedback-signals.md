# 反馈信号与路由

用户答完后的第一件事不是讲，而是判断这个回答说明了什么。

## 信号表

| 信号 | 可能含义 | 下一步 | 避免 |
|---|---|---|---|
| 空白 / “不知道” | 台阶太大、缺前置、或没理解问题 | 降一步，给具体例子；问一个更小的问题 | 重复原问题、说“再想想” |
| “不懂”但能复述术语 | 没有模型，只有词 | 要用户用自己的话讲因果；给对比案例 | 继续堆定义 |
| 答错，但推理一致 | 模型错误或前提错误 | 问“你刚才假设了什么”；用反例打破前提 | 只说“错了，应该是…” |
| 答对，理由错 | 蒙对或记忆 | 按“未过关”处理；换场景再问 | 因为答案对就放过 |
| 答对但犹豫 | 知识脆弱 | 换参数/场景，要求解释理由 | 立刻加难度 |
| 答对且自信 | 可能已稳固，可迁移 | 给边界、反例、对抗性问题 | 反复问同类题 |
| 自信但错 | 校准偏差 | 先预测再验证；对比置信度和结果 | 直接纠正而不处理自信 |
| 回答变短 / “直接说” | 过载、挫败、或时间不够 | 停止提问，给完整样例，再做一个检查 | 继续追问 |
| 跑题 | 目标漂移或问题太难 | 复述目标，问是否换方向 | 强行拉回 |
| 只问“答案是什么” | 想要结果，不想走过程 | 先给答案，再给一个最小检查 | 拒绝回答或强行教学 |
| “就看看我会不会” | 只想评估 | 只跑探针和验收任务，输出证据；不建模、不给例 | 强行教学 |
| 反复问同一概念 | 前面的讲法无效 | 换类比/换例子/降前置，不重复原话 | 用同样的话再讲一遍 |
| 用户纠正你 | 你的模型错了 | 立即承认，复述用户口径，重新探测 | 争辩或维护原判断 |

## 错误分类

先分四类，再决定回应：

1. **事实缺口**：不知道关键定义、数据、版本。补最小事实，马上回到应用。
2. **模型错误**：因果反了、把相关当因果、忽略关键变量。用对比案例重建。
3. **步骤错误**：知道原理但顺序、操作、边界错。拆步骤，让用户重走关键一步。
4. **迁移失败**：原题会，换场景不会。指出变化点，给半提示的新题。

读题错误单独处理：先复述问题和约束，不重复讲知识。

证据不足、分不出类型时，先问一个能区分两类错误的问题，不硬归类。

## 校准

自信程度也是证据：

- 高自信 + 正确 → 可以加边界和反例。
- 高自信 + 错误 → 先做预测-验证，让用户看到差距；不要只说“你错了”。
- 低自信 + 正确 → 指出理由中正确的部分，减少无效怀疑。
- 低自信 + 错误 → 降台阶，补前置，不追加难度。

不要用“你很有信心”或“你不够自信”当结论；用具体题号和结果说话。

## 提问纪律

- 一次只问一个问题。
- 连续两轮没有具体例子或可观察输出 → 停止提问，给 worked example。
- 用户明确说“直接说” → 先给完整解释，再做一个检查；不要继续苏格拉底式追问。
- 苏格拉底式追问只用于暴露假设、校准自信、探索边界；首次接触概念先给完整模型 + worked example。
- 一个问题问两次还卡 → 换讲法，不重复原问题。
- 不用“你理解了吗”“懂了吗”作为验收；要用户输出。

## 反馈话术

有效：

- “第 2 题你答对了，但理由是‘因为模型更大’，这条不成立；我们换一个参数量相同、数据不同的例子。”
- “你卡的不是公式，是‘为什么先召回再重排’；我先把两个阶段的输入输出摆出来。”
- “你现在很确定，但和实测相反；先写下你的预测，再跑一次。”

无效：

- “你好像不太理解。”
- “这个很简单。”
- “再想想。”
- “你这里有问题。”（不指出哪一行、哪一步）

## 什么时候停止提问

满足任一条件：

- 已达到“本次过关”（见 `mastery-gates.md`）；不要在教学/评估会话收束时宣布“已掌握”；掌握复测（7 天后）可以判。
- 只评估的六个验收任务跑完（含 `未测`）或用户时间用完。
- 用户明确要求直接讲。
- 连续两轮无进展，且降台阶无效。
- 用户疲劳、时间不够、或情绪明显变差。
- 目标已经变化，需要重新定契约。

停止提问不等于停止教学；可以给完整样例、学习地图和复习任务。
