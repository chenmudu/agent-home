# 四类主题工作流与通用策略

先按 `routing-signals.md` 定主工作流；主题决定证据形态，教学法由学习者水平和当前卡点决定。一次只用一个主方法。

## 模型类

目标：建立因果模型，能读实验、做判断，不被单一指标带走。

顺序：

1. **预测**：先让用户说“如果改 X，Y 会怎么变，为什么”。
2. **实测/查表**：跑一个小实验，或读一张已有表；明确口径。
3. **对比**：把预测写下来；示例/实测后第一件事是对照预测和实际，差在哪。
4. **归因**：一次只改一个变量；区分相关与因果。
5. **边界**：换数据、换规模、换硬件是否还成立。

常用动作：

- 给一个 benchmark 表，问“这个结论缺什么对照？”
- 让用户设计一个消融，而不是背消融名称。
- 用具体数字算显存/吞吐/参数量，避免只谈概念。
- 对“更大模型一定更好”这类说法，给同参数、不同数据的反例。

常见误区：

- 把 benchmark 分数当能力本身。
- 忽略数据污染、评测口径、算力预算。
- 把相关当因果，或同时改多个变量。
- 只记结论，不知道适用边界。

验收：读一个没见过的表，指出结论、混杂因素和至少一个不确定处。

## Agent Harness 类

目标：能定位、能解释状态、能做最小修复、能验证不回归。

顺序：

1. **复现**：先拿到稳定复现条件；没有就先生成最小复现。
2. **定位**：从入口、日志、状态、`file:line` 找断点；不先猜修法。
3. **解释**：说清“输入 → 经过哪些状态 → 输出/报错”。
4. **最小修复**：只改必要的一处；说明为什么不是别处。
5. **回归**：加一个能区分修复前后的测试或检查。

样例渐隐：

```text
第一轮：完整走查，我指给你看每一步
第二轮：你走主路径，我只在卡点提示
第三轮：你独立定位，我只看证据和回归
```

常用动作：

- 让用户指出“状态在哪里、谁修改它”。
- 给一个报错，先问“你先看哪里”，再一起看。
- 让用户解释一条命令的输出，而不是只记命令。
- 用真实仓库的小切片，不用伪代码替代全部。

常见误区：

- 直接改报错行，不查状态来源。
- 同时改多处，无法归因。
- 修完不写回归测试。
- 把“能跑”当“理解”。

验收：给一个没见过的报错，定位到 `file:line`，提出最小修复并写回归检查。

## 世界知识类

目标：能判断一条外部说法是否可信、是否仍有效、边界在哪。

顺序：

1. **拆 claim**：谁、什么时候、在什么范围、说了什么。
2. **找来源**：一手来源优先；记录日期和适用范围。
3. **交叉验证**：至少两个独立来源；注意是否互相抄。
4. **标不确定**：哪些能确认，哪些只能推测。
5. **更新**：有时效性的结论写“截至某日”。

常用动作：

- 让用户先给置信度，再查来源，最后对照。
- 给一条新闻标题，问“它省略了什么条件？”
- 对比官方文档、release note、媒体报道的差异。
- 对价格/政策/版本，要求写出日期和地区。

常见误区：

- 把搜索摘要当来源。
- 忽略发布日期和适用范围。
- 用一个来源证明另一个来源。
- 把“现在有效”说成“永远有效”。

验收：给一条时效性说法，找两个来源交叉验证，标出日期、范围和不确定处。

## 通用技能·程序性

目标：稳定执行 + 适应变化。

顺序：

1. **示范**：完整做一遍，边做边说关键判断。
2. **分解**：拆成 2–4 个可练片段。
3. **练习**：一次只练一个片段，重复到稳定。
4. **反馈**：即时、具体到动作/决策。
5. **变式**：换速度、条件、干扰，检查迁移。
6. **整合**：回到完整任务，在时间/约束下完成。

常用动作：

- 让用户先做一遍，不先讲理论。
- 用录像/产物/结果做反馈，不靠感觉。
- 设计一个“容易错但能区分”的变式。
- 每次只改一个动作，不一次改全部。

常见误区：

- 只看不练。
- 只练舒适区。
- 没有即时反馈。
- 不换场景，练成固定套路。

验收：给一个没见过的标准任务，在时间/约束下独立完成，并说出关键判断。

## 通用技能·概念/判断

目标：能判断、能论证、能处理边界，不是背流程。

顺序：

1. **Worked example**：完整展示一个判断，包括备选方案和取舍。
2. **对比案例**：两个相似但结论不同的案例，逼出关键变量。
3. **主动回忆**：不看材料复述规则和例外，再对照。
4. **论证练习**：给一个新案例，写结论、理由、反例、不确定处。
5. **变式**：换事实、换约束、换立场，检查判断是否稳定。
6. **整合**：在真实材料里找出适用与不适用。

常用动作：

- 让用户先判断，再给专家判断对照。
- 用“如果这条事实变了，结论还成立吗”做变式。
- 要求写出“什么条件下我会改判”。
- 用真实合同/论文/案例切片，不用伪案例。

常见误区：

- 把规则背成流程，不会处理例外。
- 只记结论，不记理由和边界。
- 用一个案例证明普遍规则。
- 不写不确定处。

验收：给一个没见过的案例或论证，判断结论是否成立，写出理由、反例和不确定处。

## 高风险/身体技能

手术、飞行、临床、极限运动等必须由持证人类教练在场监督；本技能只做知识、决策和复盘，不替代实操。

## 通用策略

| 策略 | 用法 | 适用 |
|---|---|---|
| **Worked example** | 完整展示判断过程，不只给结果 | 新手、卡住、过载 |
| **Faded guidance** | 完整示范 → 半提示 → 独立 | 通用技能·程序性、Harness 类 |
| **Contrasting cases** | 两个相似但关键不同的例子 | 概念混淆、边界 |
| **Prediction–observation–explanation** | 先预测，再看结果，再解释差异 | 模型类、通用技能·程序性 |
| **Retrieval practice** | 不看材料主动回忆 | 保持、复习 |
| **Spacing** | 24 小时 + 7 天复习 | 长期掌握 |
| **Interleaving** | 混合相近题型，迫使辨别 | 迁移、边界 |
| **Teach-back** | 让用户教给你听 | 解释闸门 |
| **Elaborative interrogation** | 多问“为什么是这样、为什么不是那样” | 建立因果 |

## 重塑动作

| 卡点 | 动作 |
|---|---|
| 太抽象 | 换具体数字/例子/图 |
| 台阶太大 | 拆子问题，先做一步 |
| 概念混淆 | 对比案例，列同异 |
| 缺前置 | 补最小前置，再回原题 |
| 已经会 | 加反例、边界、对抗题 |
| 过载 | 停止提问，给完整样例 |
| 目标漂移 | 复述目标，确认是否换方向 |

## 纪律

- 一次只用一个主教学法；需要换时说明为什么换。
- 不把四类主题的术语混着解释；主题不是教学法，教学法按卡点和水平换。
- 不为了显得系统而一次讲完所有策略。
- 策略服务于下一步动作，不服务于教案完整。
