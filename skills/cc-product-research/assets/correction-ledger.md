# 矫正账本

用户每次纠正后追加一条。**这是 skill 唯一的成长机制**：细节不是设计出来的，是被纠正出来的。

## 条目格式

```
## C-00N｜<一句话标题>
日期：
场景：<A/B/C/D/E 哪一级，什么任务>
我做的：<具体错在哪，要能指认>
纠正的：<用户原话或实测推翻>
提炼规则：<一句话，可执行>
适用范围：<哪几级 / 哪种情况>
状态：案例（默认）/ 已升级（写进 SKILL.md 或 references）
```

## 升级规则

- 同类矫正出现 **2 次**，或用户明确说"记住"，才升级为硬规则；
- 未升级的留在账本当案例，**不写进流程**（避免用一次特例绑架以后所有调研）；
- 升级后不删除原条目，标 `已升级` 并注明落点。

## 维护
