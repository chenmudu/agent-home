# 证据规则

## 四层证据

| 层 | 是什么 | 能证明 | 不能证明 |
|---|---|---|---|
| 1 实机操作 | 我点了什么，它发生了什么 | 这条路径今天在这台机器上成立 | 换环境是否成立 |
| 2 截图 | 可复核的画面 + 文件路径 | 我当时看到了什么 | 我没截到的部分 |
| 3 界面文案 | 首屏承诺、空状态、报错、忙时提示 | 产品想让用户以为什么 | 它是否做到 |
| 4 源码 | 路径 + 行号 | 机制、边界、失效模式 | 用户是否可达（有代码≠有入口） |
| 外 外部资料 | issue / PR / 文档 / 社区实测 | 别人报过什么 | 是否仍然成立（可能已修/已过期） |

## 什么叫"证实"

- 操作型：**能复现**（同样的步骤、同样的结果），并记下环境（版本、URL、账号）。
- 代码型：**能指认**（路径:行号，且读的是 SSOT 源码，不是安装产物）。
- 视觉型：**能复核**（截图文件名固定、归档、报告里被引用）。
- 外部型：**能标注**（谁说的、什么时间、我有没有复现）。

三条都达不到的，只能写"推测"，并且必须放进未验证区。

## 引用格式

```
实机：操作序列 + 结果（例：点 >5k 档 → 全选(2532) 变 全选(9)）
截图：图 N（附录 A 索引表里对应"它证明了什么"）
代码：src/index.js:211（相对仓库根；宿主代码标 packages/...）
文档：README.md:15
外部：owner/repo#52 · 2026-09-20
```

## 证据载体：单文件、图内嵌

- 交付物**只有一个 HTML**：截图转成 data URI 内嵌，不产出 `shots/` 目录。
- 位图**默认折叠**（`<details>`），展开是固定尺寸缩略图（默认 720×480，`object-fit:contain`），点击在新窗口看原图。
- 原图字节只存一份：点击时读 `this.src` 打开，不要为"放大"再复制一份 data URI。
- 全部 `loading="lazy"`；SVG 示意图不折叠（矢量、体积小）。
- 截图先压到 ≤1280px 宽再内嵌；成品超过 8 MB 就重新压缩。
- 附录 A 只做索引（图号 / 内容 / 所在段），不再列文件路径。

## 降级声明（必须写在报告第一页）

- **没跑起来**（无实例 / 无法访问 / 无权限）→ "本次未获实机证据，所有能力仅视为宣称。"
- **无源码**（商业产品 / 只发布产物）→ "本次未获实现证据，机制部分仅依据文档与行为推断。"
- **只读受限**（不许执行写操作）→ "本次未执行任何写操作，涉及写入路径的结论为源码判定、未实测。"

## 数字纪律

一个数字出现前先问四件事：

1. **口径**：累计值、快照值、还是单次请求值？
2. **尺子**：谁算的（宿主计量 / 自建分词器 / 字符数估算）？
3. **分母**：比的是原始历史，还是"在位者"的产物？
4. **时刻**：同一会话的同一时刻吗？

口径不同的数字，禁止相减、相加、比倍数。要放在一起，先换算并写明假设。

## 陷阱清单（全部来自实战）

| 陷阱 | 症状 | 防法 |
|---|---|---|
| 截图认对象 | 用户截的图和真实包名不一致 | 对象以安装清单 / `package.json` 为准，截图只作线索 |
| 安装副本当基线 | 本机被改过，与上游不一致 | 上游 tag 为 SSOT；副本差异单独列（`diff --strip-trailing-cr`，别被 CRLF 骗） |
| 跨会话混数 | 把 A 会话的数字用来解释 B 会话 | 每个数字标会话 id / 时间 |
| 只截图不动手 | 能说出界面长什么样，说不出点下去会怎样 | 能跑的必须点；点了必须记结果 |
| 自造安全结论 | "应该挡不住"写成了"挡不住" | 安全 / 边界结论必须实测，或标"未实测" |
| 全信子 agent | 子代理的结论直接进报告 | 关键结论由主 agent 复核源码；抽查比例 100% |
| 重写丢章节 | 改版后用户要过的章节消失 | 交付前用 `assets/requirements.md` 逐条打勾 |
| 图号漂移 | 图 16 出现在图 12 前面 | 跑 `scripts/check_doc.mjs`，图号必须按文档顺序递增 |
| 文档当事实 | README 说的直接写进结论 | 一律先归入"宣称"列，再用界面 / 代码核对 |

## 未验证区的写法

不是"还有很多没看"，而是逐条写清：

```
- <结论>：依据是 <A>，但 <B> 未做（原因：无权限 / 无实例 / 只读约束 / 成本太高）。
  影响：如果 <B> 与预期相反，则 <结论> 需要改为 <替代结论>。
```

这样读者知道"错的话会错在哪"，而不是只知道"可能不准"。
