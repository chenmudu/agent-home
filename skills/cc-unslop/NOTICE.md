## Changes made in this fork (2026-11-05, agent-home)

1. Frontmatter `description` narrowed so this skill only triggers on an interface that already
   exists — source files, a live URL or a screenshot. Mentions of building or designing a screen from
   scratch, and of redesigning it from a new direction, were removed, because those now belong to
   `cc-design-taste-frontend`.
2. Two short paragraphs added after the credit: a "modified locally" note and a "where this starts and
   stops" boundary that hands builds from zero and full rebuilds to `cc-design-taste-frontend`.
3. `LICENSE` (CC BY 4.0) and `CITATION.cff` copied verbatim from upstream.
4. Renamed to `cc-unslop` (directory and frontmatter `name`), so every skill in this repository
   carries the same prefix.
5. `SKILL.md` is now a Chinese translation; the original English text is kept verbatim as `SKILL.en.md`.
   The translation keeps the nine passes, the numbers, the flags and the credit; only prose was
   translated.

No other file was modified: the run, the nine passes, `references/` and `scripts/` are upstream as-is.
